# 01. プロジェクト概要 & リサーチ結果

> 出典: RFC §1 を整形。

- **正式サービス名**: プレゼンタイマー
- **公式ドメイン**: [presentation-timer.net](https://presentation-timer.net)

## 💡 背景と市場の機会

- **現状の課題**: Android 市場（Google Play）における「アジェンダ登録型・全画面プレゼンタイマー」は、UI/UX が古いものが多く、モダンで使いやすいアプリの選択肢が少ない。
- **先行競合**:
  - iOS: 『TimePacer』
  - Web: 『Stagetimer』
  - これらは強力だが、**Android ネイティブで同等以上の体験**を提供するプロダクトはまだ少なく、付け入る隙（ブルーオーシャン）がある。
- **狙う体験**: 事前にアジェンダと時間配分を登録。本番中はスマホ画面いっぱいに現在の進捗を大きく表示し、時間が押した／巻いた際の **自動時間再配分ロジック** を備えたモダンなタイマー。

## 🚀 開発戦略

React Native を軸にした **モノレポ（Monorepo）構成** を採用する。

- Android アプリをメインのターゲットとする。
- 同じコードベースから「iOS アプリ」および「Web アプリ（大画面共有用・管理用）」へのマルチチャンネル展開を **最小コスト** で実現する。

### 差別化軸（まとめ）

| 観点 | 本アプリの狙い |
|---|---|
| プラットフォーム | Android ネイティブ品質を主軸に iOS / Web も同時提供 |
| 体験 | フルスクリーンの特大進捗表示でステージ用途に最適化 |
| 独自性 | 押し/巻きに自動追従する **時間再配分ロジック**（詳細は [05](./05-core-logic.md)） |
| UI/UX | 競合の「古さ」に対し、モダンで直感的な操作性 |
