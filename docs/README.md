# アジェンダタイマーアプリ 設計ドキュメント

プレゼン用アジェンダタイマーアプリ（Android をメインターゲットとし、iOS / Web へマルチチャンネル展開する React Native モノレポ）の設計ドキュメント群でござる。実装着手前の **RFC（Request for Comments）** として、関係者のレビューと合意形成を目的とする。

## 読み方

初見の場合は `01` → `02` → `03` の順で全体像（何を・どの技術で・どう配置するか）を掴み、続いて本アプリの核心である `04`・`05`（データモデルと再配分ロジック）へ進むと理解が早いでござる。

## ドキュメントのステータス

- **段階**: MVP 実装済み（`apps/mobile`）→ Phase 2（`fixed-end` モード・iOS 配布）へ移行中。詳細は [07. ロードマップ § 現在の実装状況](./07-roadmap.md#現在の実装状況概況) を参照
- **確定度**: §1〜3 は提示済み RFC ベース / §4〜7 は提案ベースとして起草し、その後 MVP スコープで実装済み
- **進行管理**: MVP の全ステップを GitHub Issue 化済み。ラベルの定義と運用方針は [08. 実装ラベルの運用](./08-implementation-issues.md) を参照
- **次アクション**: `fixed-end` モードの再配分ロジック実装（Issue #90）と iOS 配布作業
