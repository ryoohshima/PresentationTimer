# アジェンダタイマーアプリ 設計ドキュメント

プレゼン用アジェンダタイマーアプリ（Android をメインターゲットとし、iOS / Web へマルチチャンネル展開する React Native モノレポ）の設計ドキュメント群でござる。実装着手前の **RFC（Request for Comments）** として、関係者のレビューと合意形成を目的とする。

## 読み方

初見の場合は `01` → `02` → `03` の順で全体像（何を・どの技術で・どう配置するか）を掴み、続いて本アプリの核心である `04`・`05`（データモデルと再配分ロジック）へ進むと理解が早いでござる。

## ドキュメントのステータス

- **段階**: RFC（実装前の設計レビュー）
- **確定度**: §1〜3 は提示済み RFC ベース / §4〜7 は提案ベース（要レビュー）
- **次アクション**: `05-core-logic.md`（時間再配分アルゴリズム）を最優先でレビューし、合意後に `packages/core-logic` の実装へ進む
